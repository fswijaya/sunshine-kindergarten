# Sunshine Kids Kindergarten

A colorful, playful kindergarten landing page built with React, Vite, Tailwind CSS, and Convex.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite 6
- **Styling**: Tailwind CSS 4, shadcn/ui
- **Animations**: Motion (Framer Motion)
- **Backend**: Convex
- **Auth**: Hercules Auth

## Sections

- **Hero** - Animated gradient background with floating shapes
- **Features** - 6 tilted feature cards with scroll animations
- **Programs** - 3 program tiers (Morning Explorers, Rainbow Learners, Rocket Readies)
- **Gallery** - Mosaic photo grid with hover effects
- **Testimonials** - Rotating parent reviews carousel
- **Contact** - Inquiry form with school info
- **Footer** - Links and branding

## Getting Started

```bash
pnpm install
pnpm dev
```
